2. Safe SEO & Heading Structure Optimization / Optimizacija SEO in strukture naslovov

English: Problem & Resolution

Diagnosis: The SEO checker reported "No H1 found" and a text-to-code ratio of 0.61% (only 6 words detected). This occurred because previous content was placed inside a <noscript> block, which crawlers routinely strip.

Resolution: We migrated the structured semantic content directly into <div id="root">. When React mounts, it replaces the element seamlessly. Crawlers immediately read full HTML.

Slovenščina: Težava in rešitev

Diagnoza: SEO orodja so poročala o "Manjkajočem H1 naslovu" ter le 6 zaznanih besedah (0,61% razmerje besedila proti kodi). Razlog je bil v tem, da je bila vsebina znotraj oznake <noscript>, ki jo iskalniki prezrejo.

Rešitev: Strukturirano slovensko vsebino smo premaknili neposredno v <div id="root">. Za uporabnika ni nobene vizualne razlike, iskalni pajki pa takoj prepoznajo celotno vsebino.

3. Web Accessibility (WCAG 2.1 AA) / Dostopnost spletnega mesta

English: Touch Targets & Contrast

Touch Targets: Hero slider dots had a clickable bounding box of 8×8 px, failing Google Lighthouse mobile tap target criteria. We expanded each dot's touch zone to 44×44 px without changing the visible 8px/24px pill design.

Color Contrast: Adjusted secondary teal and meta text shades to surpass the WCAG 4.5:1 minimum threshold.

Slovenščina: Dotiki in kontrasti

Območja za dotik: Navigacijske pike v osrednji pasici (hero dots) so imele velikost le 8×8 px. Interaktivno območje smo razširili na 44×44 px, pri čemer je vidni videz ostal popolnoma enak.

Barvni kontrasti: Natančno smo prilagodili odtenke sekundarnih gumbov in spremnih besedil, da vsi presegajo zahtevan standard 4,5:1.

4. Website Performance & Server Caching / Hitrost nalaganja in predpomnilnik

English: Performance Optimizations
  • Eliminated Render-Blocking Fonts: Plus Jakarta Sans now uses non-blocking asynchronous loading with font-display: swap, preventing First Contentful Paint delay.
  • 1-Year Immutable Caching: Configured Apache/LiteSpeed .htaccess headers for Hostinger. Static JS, CSS, fonts, and images now cache for 1 year (max-age=31536000, immutable).
  • HTML Freshness: index.html set to no-cache so visitors receive updates immediately upon deployment.
Slovenščina: Hitrost in predpomnjenje
  • Odpravljeno blokiranje upodabljanja: Pisava Plus Jakarta Sans se zdaj nalaga asinhrono z font-display: swap, kar omogoča takojšen prikaz strani.

  • Vedno sveža HTML koda: index.html ima oznako no-cache, kar zagotavlja, da obiskovalci takoj vidijo novo različico po posodobitvi.
